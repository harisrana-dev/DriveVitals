# 🚗 DriveVitals

DriveVitals is an enterprise-inspired Fleet Intelligence Platform developed as a Final Year Project.

The platform transforms raw vehicle telemetry into actionable fleet intelligence through real-time analytics, driver behaviour monitoring, vehicle health assessment, maintenance recommendations, and historical fleet trends.

---

## Features

- Real-time vehicle telemetry
- Driver Behaviour Analysis
- Vehicle Health Monitoring
- Fuel Efficiency Analytics
- Driver Ranking
- Maintenance Queue
- Fleet Performance Trends
- Live Fleet Dashboard
- WebSocket-based real-time updates
